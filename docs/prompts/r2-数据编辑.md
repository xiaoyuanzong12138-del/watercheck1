实时显示：最高日 Qd = q×N/1000 (m³/d)、最高时 Qh = Qd×Kh/24 (m³/h) = Qd×Kh/86.4 (L/s)。
「按人口分配到楼栋节点」按钮：把 Qh 按各楼栋人数比例写进节点 demand，水源与普通节点置 0。

【三、节点表】
列：类型（下拉 水源/节点/楼栋）、编号、需水量 L/s、地面标高 m、是否定压（开关）、定压水头 m；
类型选了「楼栋」时，额外显示三列：层数、户数、人数。
每格是 input：失焦保存、Tab 跳下一格、Enter 下移一行。行尾删除按钮，表底「+ 添加节点」。
支持「粘贴 CSV」弹层：逗号/制表符/中文逗号都认，首行可为表头。

【四、管段表】
列：编号、起点（下拉，取节点 id）、终点（下拉）、管长 m、管径 mm、C 值（带 90/100/130/140/150 常用值提示）、删除。
表底「+ 添加管段」，同样支持 CSV 粘贴。

【五、校核参数】经济流速 vMin/vMax、1–6 层服务水头表（都可编辑）。

【六、校验（实时，显示在表格上方「问题列表」；点条目滚动并高亮对应格子）】
1. 节点编号为空或重复
2. 管段编号为空或重复
3. 管段起点/终点不存在，或起点=终点
