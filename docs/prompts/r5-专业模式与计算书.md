现在只做这一件事：专业模式的结果页 + 计算书打印页 + CSV 导出。不要改体检报告的文案与结论逻辑，也不要先解释计划。

【一、#/result/:id 计算结果页（专业模式入口）】
从工程页「专业模式」开关打开后进入，或工程页加一个「查看平差结果 →」入口。
1. 指标卡：迭代次数 / 最大环闭合差(m) / 最大节点连续性残差(L/s) / 总需水量(L/s) / 进水流量校核（进水量与总需水量差 < 0.001 显示「守恒 ✓」，否则显示差值）。
2. 管段结果表：管段 | 起点 | 终点 | 管长 m | 管径 mm | C | 流量 L/s | 流速 m/s | 水头损失 m | 1000i | 状态
   - 流量为负时显示「反向」标记；流速超出 vMin/vMax 的行标橙；状态列给 pill（经济 / 偏慢 / 偏快）。
3. 节点结果表：节点 | 需水量 L/s | 地面标高 m | 水头 m | 自由水压 m | 相当于可供 N 层。
4. 环闭合差明细表：环号 | 组成管段（按环序）| 闭合差 m（科学计数，3 位有效数字）。
5. 收敛曲线：SVG 折线图，x = 迭代次数，y = 每轮 max|ΔQ|（对数轴，标注数量级），并在收敛点标注「第 N 次收敛」。
6. 三个导出按钮：导出管段 CSV / 导出节点 CSV / 导出环 CSV。要求：UTF-8 BOM、逗号分隔、带表头、文件名形如 幸福里-管段.csv。
7. 页脚一行：计算方法说明（海澄-威廉公式 + 哈代-克罗斯环校正），以及「本页数据来自恒定流平差计算」。

【二、#/report/:id 计算书（A4 打印页）】
1. 用 @media print 隐藏导航、按钮、页脚操作区，只保留正文；A4 纵向，页边距 18mm，字号 10.5pt / 行高 1.6。
2. 章节：
   一、工程概况（名称、计算日期、人口、定额、Kh、Qd、Qh）
   二、设计参数与公式（写出 海澄-威廉 h=10.67·L·Q^1.852/(C^1.852·D^4.87)、环校正 ΔQ=−Σh/(1.852·Σ|h/Q|)、服务水头表）
   三、节点表
   四、管段表
   五、平差结果表（管段 Q/v/h/1000i）
   六、节点水头与自由水压表
   七、校核结论（流速、水压、闭合差逐项「满足 / 不满足」）
   八、计算假定（恒定流、沿程损失按海澄-威廉、局部损失并入沿程、单一水源）
3. 页脚：第 X 页 / 共 Y 页 + 工具名与版本 + 生成时间。
4. 表格跨页时表头重复（thead 重复）；避免整行被裁断（tr { break-inside: avoid }）。
5. 顶部一个「打印 / 另存为 PDF」按钮（window.print()），打印样式里隐藏该按钮。

【三、入口串联】
- 工程页「专业模式」开关打开 → 显示「查看平差结果」「打印计算书」两个入口；关闭 → 隐藏。
