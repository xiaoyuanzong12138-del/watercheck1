现在只做这一件事：给刚做的 3D 剖面楼加「水爬升」动画 + 三段叙事 + 三方案联动，并把立体感补强。不改求解逻辑。

【一、先把立体感补强（同一轮做，别另起一轮）】
1. 屋顶做出厚度：顶面加一块 8px 厚的板（与正面同色系但更亮），下面一层深色阴影线；
2. 正面（剖切面）用更亮的填充，并在左右边缘各加一条 2px 深的侧墙线，让人一眼看出这是剖开的；
3. 地面投影加长一点（向右下 20px），做出楼落在地上的感觉；
4. 立管加粗到 12px，颜色加深到 #2E8FD0，有水段的管壁加一条更亮的 2px 高光。

【二、水爬升动画（核心）】
进入体检页、结论算出来后自动播放一次（约 2.6 秒），并提供「重播」小按钮。
时间轴（用 requestAnimationFrame 驱动，不要引第三方库）：
t=0 → 0.3s：立管空，进水管先亮一下（左侧折线淡入）；
0.3s → 1.8s：水柱从管底匀速上升，高度 = 供到层数/总层数 × 楼高；
   每升高一层，该层楼板线闪一下（0.15s 高亮后回落）；
   水柱顶端画 3 段 sin 波浪（周期 1.2s，振幅 3px），内部 5 个气泡向上飘（速度 ∝ 流量）；
1.8s → 2.1s：水柱**再冲高 0.3 层**，碰到上面楼板后**回落 0.25 层**（先越过再退回来，肉眼可辨）；
2.1s → 2.6s：水柱上方各层楼体透明度降到 0.45、轮廓变虚线；右上角出现「N 层以上：高峰期没水」；
   水位线高光 + 绿色标签「X 层 · Y m」淡入。

【三、三方案联动】
结论卡下方三个按钮（若当前只显示两个方案，就按现有方案数来）：
1.「加一台增压泵」→ 播放「水柱涨到顶层、全部楼层变绿、标签更新为新水压」的动画（0.8s ease-out），播放期间按钮禁用；
2.「把主管换成更大的管」→ 水柱按**真实试算结果**涨到对应层数（可能只涨一点点，不许编）；
3.「5–6 层单独二次加压」→ 只让上半部分楼层变绿，水柱在上半段从半高位置向上补满（下半段不变）。
每个动画结束后保留结果状态；点「恢复原状」回到初始水位并重播初始动画。

【四、兜底与性能】
1. prefers-reduced-motion: reduce 时跳过动画，直接显示最终状态；
2. 动画只在页面可见时播放（document.hidden 时暂停），页签切回不重播；
3. 18 层的示例：水位只到 0 层，动画表现为「水刚进管口就停住」，必须能正常播放不报错；
4. 所有数值（供到几层、水压、涨到几层）必须来自求解结果，不许写死。
