【项目技术约束 · 不可违反】
1. 这是一个零构建的纯静态网站：原生 HTML + CSS + 经典 JavaScript（经典脚本，不用 type=module）。禁止 React/Vue/TypeScript 框架/打包工具/npm 依赖/构建步骤。
1b. 模块化用「经典脚本 + window.WC 命名空间」：每个文件一个 IIFE，挂到 window.WC 下（WC.solver / WC.store / WC.samples / WC.ui.networkMap / WC.app），index.html 用普通 script 标签按依赖顺序加载。不要写 import/export，全局只允许暴露 window.WC。原因：双击 index.html（file:// 协议）时浏览器会以 CORS 为由拒绝加载跨文件 ES Module，必须保证「双击就能打开」。
2. 目录结构固定：index.html、styles.css、app.js（入口）、solver.js（求解内核）、samples.js（示例数据）、ui/（组件模块）、tests.html（浏览器内数值自检页）。
3. 不联网、不登录、无后端。所有数据只存 localStorage（键名 wc.projects.v1）。
4. 中文界面，文案说人话，术语第一次出现时加括号解释。
5. 兼容 Chrome/Edge/Safari 近两年版本；手机端（375px 宽）必须能完整操作。
6. 这是 TRAE 好应用大赏赛的参赛作品，请全程在本对话中完成开发与迭代。

请从零搭建「水压体检」的骨架。

【这是什么】一个给水管网水力体检工具：录入小区管网节点与管段，用环状管网平差算出各楼栋水压，用白话告诉业主「6 层楼只能供到 2 层」，并给出加压/换管建议；专业模式可看完整平差表并导出计算书。

【本轮只做骨架，不做计算】
1. 零构建静态站点骨架：index.html 用普通 script 标签依次引入 solver.js、samples.js、store.js、ui/network-map.js、app.js（全部为经典脚本，IIFE + window.WC 命名空间，不用 type=module、不写 import/export）。hash 路由：#/home、#/project/:id、#/edit/:id、#/result/:id、#/report/:id。
